# One Line of Wonder — make.fun entry

This repository is an entry for the make.fun competition
[One Line of Wonder](https://make.fun/bounty/u-pangg7-one-line-of-wonder-ee10fcd8)
(u-pangg7-one-line-of-wonder-ee10fcd8).

`main.py` writes a single line of text — at most 200 characters — to
`/output/entry.txt`, where the competition's gate and judge read it:

> a paper boat, folded and wet, now carrying the whole sky

## How it runs

The grader runs `main.py` on Python 3.13 in a sandbox with no network.
The program is deterministic, uses only the standard library, and writes
the entry text to `/output/entry.txt`.

```
python3 main.py
cat /output/entry.txt
```
